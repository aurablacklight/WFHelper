## Changes in beta.7

- The Feedback button opens a form again, and you do not need a GitHub account. Reports go to this beta's private Discord channel, along with any screenshot you attach. The app log is only sent if you tick the box, and tokens, emails and file paths are removed from it.
- Inventory rows keep the prices that did load when part of a lookup fails, and retry missing icons.
- The wiki credit now names the wiki's actual licence, CC BY-NC-SA 3.0.
