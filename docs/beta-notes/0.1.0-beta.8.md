## Changes in beta.8

- Star chart completion on the Mastery page now counts the same 238 nodes and 13 Junctions the game counts for unlocking The Steel Path. It used to count only nodes that give mastery, so Void, Lua, Kuva Fortress, Deimos and Dark Sector nodes were missing and the total showed 169.
- Bug reports now also say whether you're signed in to warframe.market and whether Warframe is running. You can see both in the form before you send it.
